# Ninjago — Master Army Roster

**Purpose:** reference sheet for building game characters. Organised by faction, then by command tier.
**Source:** Ninjago Wiki (Fandom) + LEGO Ninjago official set/character material.
**Tier key:** `LORD` = faction ruler/warlord · `CMD` = general / commander / named lieutenant · `ELITE` = named unique fighter · `TROOP` = generic rank-and-file unit type

Each entry has an empty `Image` column for you to fill in later.

## Design / balance notes for the game

- **Consistent 4-tier ladder.** Skulkin, Serpentine, and the Stone Army all use a clean *General → Warrior → Soldier → Scout* structure. That maps almost 1:1 onto a boss / elite / line / ranged-skirmisher unit template you can reuse for every faction.
- **Serpentine promotion mechanic** is a free gameplay idea: beating a general in a duel swaps the models (legs ↔ tail). Fun for a kid.
- **Faction gimmicks worth building into stats:**
  - Stone Army — immune to normal damage, but bound to the Helmet of Shadows (capture-the-item objective).
  - Ghost Warriors — destroyed instantly by water.
  - Vermillion — re-form after being scattered.
  - Vengestone units — nullify elemental powers.
  - Serpentine — cold-blooded; weaker in cold/shade, stronger in sun.
- **Colour palettes are already faction-coded:** Skulkin (bone + elemental accent), Serpentine (one colour per tribe), Stone Army (black/red/green glow), Nindroids (black/silver/teal), Vermillion (red/dark grey), Blizzard Samurai (white/blue), Imperium (gold/white/teal).

## Confidence notes
- Skulkin general/element pairings (Wyplash–Ice, Kruncha–Earth, Nuckal–Lightning, Samukai–Fire) come from set material and are slightly inconsistent between sources — worth a second check if it matters.
- *Dragons Rising* Seasons 3–4 rosters (Administration, Forbidden Five, Loyalists) are the newest material and the least settled on the wiki.
- Anything marked "non-canon" on the wiki (game-only characters like Talon, Nitro, Sawyer, Buffer, Cardinsto) has mostly been left out or flagged.
